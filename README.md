# Career Hub – IT Job Portal

A lightweight, production-friendly static job portal UI built with **HTML, CSS and vanilla JavaScript**. It is intentionally dependency-free so it can be deployed to Vercel without npm/build/dependency failures.

## Features
- 40 IT job roles
- Search by title, skill or company
- Location, category and job-type filters
- Job details
- Save jobs
- Login/profile flow
- Resume PDF validation (max 5 MB)
- Apply Now form
- Duplicate application prevention
- My Applications tracking
- Recruiter dashboard demo
- Recruiter contact via email client
- Responsive mobile design
- Smooth header-to-footer navigation
- LocalStorage persistence
- Vercel-ready with no build step

## Deploy on Vercel
Import this repository and use:
- **Framework Preset:** Other
- **Root Directory:** `.`
- **Build Command:** leave empty
- **Output Directory:** `.`
- **Install Command:** leave empty

There are **no npm dependencies**.

## Important production note
The static version intentionally does not pretend to send real emails or provide secure server-side authentication. For production, connect a backend/database and an email provider. The current application flow stores demo data in the browser and opens the recruiter's email client when contacting a candidate.
